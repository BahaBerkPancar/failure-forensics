STEPS:
1. **Instrumentation without edits**: wrap the generator (a `SqlGenerator` proxy recording prompt
   question, attempt number, previous errors, returned SQL/refusal), and wrap/monkeypatch-free
   compose the pipeline: call t2s's public pieces in the same order `answer()` does if `answer()`
   can't be observed from outside, **or** use a context-local hook (e.g. wrap the validator and
   executor callables passed/imported) — choose the least invasive approach that captures steps
   `generate`, `validate`, `execute`, `compare` (vs gold, for questions) and `guard` outcome (for
   attacks). Document the approach and its limits in DECISIONS.
2. **Semantic failures**: mark `blocked` (validator/DB refused a question that has gold SQL → over-
   blocking), `wrong_result` (rows differ from gold; reuse t2s's comparison), `refusal`,
   `unsafe` (an attack prompt whose SQL executed and touched denied data or wrote — use a DB
   checksum before/after like t2s's bench), `timeout` (statement timeout).
3. **Runner**: `ff t2s run --generator gold|mutated:<name>|recorded:<path> --db traces.db` runs all
   questions + attack prompts on the t2s test DB (`TEST_DATABASE_URL`; reuse t2s's own schema/seed
   setup the way its tests do; never touch other databases).
4. **Demo**: `examples/t2s/run_demo.sh` runs gold + 2–3 mutated generators into
   `examples/t2s/demo.db` and prints `ff clusters --by-tag generator`; commit the DB if < 2 MB.
   Expected clusters documented in README (e.g. `compare:wrong_result` from wrong joins,
   `validate:blocked FUNCTION_NOT_ALLOWED` from an allowlist miss, `execute:timeout` from a
   Cartesian join). Investigate rather than tune if expectations fail.
5. **M1 review nits**: culprit fallback when the run body raises outside any step (blame the root,
   not an earlier handled step); KeyError keys keep their shape but digits → `<n>` (`'sku-<n>'`);
   `ff gc` never deletes spans of runs younger than the cutoff even when unfinished (use span
   start time); redact.py plain-quoted value branch handles escaped quotes
   (`"(?:[^"\\]|\\.)*"`); README limits mention bare 32-hex API keys (e.g. Datadog style) pass.
6. **Tests**: proxy generator records attempts; each semantic failure kind on a few real cases
   (pg-marked); core tests pass without the extra; the nits above.
7. Docs: README section "Tracing text-to-sql-guardrails", DECISIONS, CHANGELOG.
